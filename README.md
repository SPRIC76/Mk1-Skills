# MK1 skills

Agent skills by MK1. **Get them at [mk1made.us](https://mk1made.us)**, the home of every release.

This repository holds the released copies only, so skill directories and agents can find them. Each folder under `skills/` is a self-contained skill in the Agent Skills format: a `SKILL.md`, the files it runs, and its licence. Copy one into a skills folder your agent reads, such as `~/.agents/skills/`.

| Skill | What it does |
|-------|--------------|
| [Skillshaper](skills/skillshaper/SKILL.md) | Gets any skill ready for any agent. |
| [Promptaudit](skills/promptaudit/SKILL.md) | Finds instructions that went stale. |
| [Hillgate](skills/hillgate/SKILL.md) | Proves a change helped before you keep it. |
| **The Triad** | Keeps a project self-aware, in sync and lean. |
| [DevCom5](skills/devcom5/SKILL.md) | What the project knows about itself. |
| [Synk182](skills/synk182/SKILL.md) | Keeps two copies in agreement. Writes nothing until you approve, and backs up each file first. |
| [Solid8](skills/solid8/SKILL.md) | Unifies without losing meaning. Archive first. |
| **The Proof Pack** | Proves the work before anyone calls it done. |
| [Verifox](skills/verifox/SKILL.md) | Proves your work before you call it done. |
| [Testcatch](skills/testcatch/SKILL.md) | Writes tests that actually go red when it breaks. |
| [Browsetest](skills/browsetest/SKILL.md) | Measures the page instead of trusting the screenshot. |
